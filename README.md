# TaskFlow — To-Do List Web Application

A responsive, accessible task manager built with HTML5, CSS3, and vanilla JavaScript.

## Features
- Add, edit, delete, and complete tasks
- Filter tasks by All, Active, and Completed
- Clear all completed tasks
- Persist tasks and theme preference with `localStorage`
- Light/dark mode toggle
- Responsive layout for desktop and mobile
- Keyboard focus styles, skip link, labelled controls, and live announcements
- No external libraries or build tools required

## Run locally
1. Extract this folder.
2. Open `index.html` in a browser, or open the folder in VS Code and use Live Server.
3. Add tasks and refresh the page to verify local persistence.

## Files
- `index.html` — page structure
- `assets/style.css` — responsive styling and themes
- `assets/script.js` — task interactions and persistence

## Notes
Tasks are stored in the current browser on the current device. This is a front-end project; it does not sync between devices or users.
